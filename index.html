supermaker

weekly Angebote → price history

Follows the weekly offers across the big German chains — REWE, Lidl, ALDI and the rest — plus the organic Biomärkte, tracks the products you actually buy, and shows how each price moves over time. A quiet personal tool so you never overpay for the same yoghurt twice.

the hard part — pulling offers from two undocumented sources — an unofficial leaflet API and the internal page-data JSON behind a Gatsby site — through one pluggable adapter interface, and running the slow, rate-limited daily fetch as a CI job because a stateful app with a database doesn't fit the serverless model it deploys onto.

Next.js · TypeScript · Drizzle · SQLite / Turso · GitHub Actions

artemator ↗

open calls → one dashboard

Scrapes art-funding open calls from a dozen sources, dedupes them, guesses region and type, flags what's new and tracks deadlines. A GitHub Action refreshes it daily and redeploys — a site that maintains itself so artists can spend the time applying instead of searching.

the hard part — keeping a dozen mismatched RSS and HTML sources deduped and self-checking with nobody watching. A source that silently starts returning zero has to announce itself on a health strip, not just quietly vanish from the results.

Python · SQLite · GitHub Actions · Netlify

synth detective ↗

track → patch notes

Name a track — Windowlicker, Da Funk, anything — and it works out which synths probably made those sounds and how you'd patch them yourself. Music-nerd archaeology, powered by an LLM behind a serverless API.

the hard part — getting an LLM to return structured, trustworthy patch data through a stateless serverless function, and degrading gracefully when the model gives you something you can't use instead of showing the user a stack trace.

spotitube

liked songs → local mp3s

Reads your Spotify Liked Songs, then goes and finds each one on YouTube and pulls it down as an MP3. A small command-line pipeline for keeping an offline, portable copy of a library that only ever lives in someone else's cloud.

the hard part — matching a Spotify library to YouTube with no shared identifiers. Fuzzy search hits, wrong-length uploads and live versions all have to be filtered down to the one right audio match — and the whole thing stays testable, with a fully mocked suite that needs no network or credentials.

Python · Spotify API · yt-dlp · pytest

kalendarski ↗

weather → color

A macOS-style calendar where the background is an hour-by-hour temperature heatmap — your week, painted by the forecast. Night hours cool into blue, afternoons burn toward red, and the gradient shifts as the weather does.

the hard part — repainting the whole calendar from live hourly forecasts without hammering the API. The weather is cached and interpolated between fetches, so the gradient stays smooth instead of stepping every time a request lands.

React · TypeScript · Vite · OpenWeatherMap

About

the person behind the waveform

I'm Oleksandr — Sasha to most people. Engineer from Lviv, based between Hamburg and Gießen. Ten years of production Java and Python behind me; today I design and ship AI agents at taliox — LLM systems built to be reliable, not just impressive.

Before the web work I was a research engineer on JRODOS, the EU's nuclear-emergency decision-support system — a doctoral researcher (аспірант) at the Institute of Mathematical Machines and Systems (NASU, Kyiv) under Mark Zheleznyak. I built the engineering layer around the hydrological models: Java plugins, model wrappers and GIS pipelines for radionuclide transport in rivers — Chernobyl contamination maps, the Niida catchment for the Fukushima group, and a real-time exchange that pushed WRF forecasts between Ukraine and Romania for transboundary flood warning on the Prut. The dissertation never got finished; the engineering instinct did.

That's the through-line. Every project here takes a signal — weather, a river, sound, a room full of people — and builds the system that lets it speak. The waveform up top isn't decoration: hit ▶ hear this waveform and the page plays its own moving signal back as audio. Sound is part of the practice, not a garnish.
