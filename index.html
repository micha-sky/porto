Selected work

four signal problems, solved for fun

braino ↗

EEG → music

Wear a Muse headband, think, and listen back. braino maps the five brainwave bands to oscillators, quantizes them to a musical scale, adds reverb and rhythm, and renders stereo audio — offline from a CSV, or live in the browser while the signal streams in over OSC.

Python · DSP · WebAudio · OSC · FastAPI

kalendarski ↗

weather → color

A macOS-style calendar where the background is an hour-by-hour temperature heatmap — your week, painted by the forecast. Night hours cool into blue, afternoons burn toward red, and the gradient shifts as the weather does.

React · TypeScript · Vite · OpenWeatherMap

synth detective ↗

track → patch notes

Name a track — Windowlicker, Da Funk, anything — and it works out which synths probably made those sounds and how you'd patch them yourself. Music-nerd archaeology, powered by an LLM behind a serverless API.

React · Netlify Functions · Claude API

artemator ↗

open calls → one dashboard

Scrapes art-funding open calls from a dozen sources, dedupes them, guesses region and type, flags what's new and tracks deadlines. A GitHub Action refreshes it daily and redeploys — a site that maintains itself so artists can spend the time applying instead of searching.

Python · SQLite · GitHub Actions · Netlify

also: sannaleone.com and unwohl.com — artist sites built to order · spotitube — Spotify ↔ YouTube playlist matching · this site's previous life — CSS-transform surrealism, 2022

The rest of the time I chase signals: EEG, weather, sound. Most of my side projects are excuses to turn one of them into another.
